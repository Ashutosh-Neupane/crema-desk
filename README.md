# Crema

Modern headless frontend for Frappe, built with Next.js 16 + Tailwind CSS v4.

## Structure

- `crema-frontend/` — Next.js application (BFF proxy, desk shell, DocType views, forms, reports)
- `frappe/` — Frappe backend (not tracked in this repo)

## Getting Started

```bash
cd crema-frontend
npm install
npm run dev
```
